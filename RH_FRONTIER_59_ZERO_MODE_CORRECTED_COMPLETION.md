# Frontier 59 — zero-mode-corrected modular completion

## Exact identity
Let
\[
\theta(t)=\sum_{n\in\mathbb Z}e^{-\pi n^2t},\qquad
\theta_+(t)=\sum_{n\ge1}e^{-\pi n^2t}=\frac{\theta(t)-1}{2}.
\]
The coefficient measure is
\[
\rho_+(x)\,dx=e^{x/4}\theta_+(e^x)\,dx,\qquad x\ge0.
\]
Using \(\theta(e^{-x})=e^{x/2}\theta(e^x)\), the modular image is
\[
e^{-x/4}\theta_+(e^{-x})
=e^{x/4}\theta_+(e^x)+\frac12\left(e^{x/4}-e^{-x/4}\right).
\]
Thus the exact defect from evenness is
\[
\boxed{\rho_+(-x)-\rho_+(x)=\sinh(x/4).}
\]

## Correct symmetrization
For any even polynomial A(x) for which the integrals converge,
\[
\int_0^\infty A(x)\rho_+(x)\,dx
=\frac12\int_{-\infty}^{\infty}A(x)\rho_+(|x|)\,dx.
\]
This is an even extension by definition, not a modular identity. If modularity is used to rewrite the negative half-line in terms of positive x, the explicit correction \(\sinh(x/4)\) must be retained.

## New structural target
The Turan defect should therefore be decomposed into
\[
\mathcal T_m=\mathcal T_m^{\mathrm{theta}}+\mathcal T_m^{\mathrm{zero}},
\]
where the first term uses the modularly paired nonzero-theta contribution and the second is an explicit finite combination of elementary integrals generated by \(\sinh(x/4)\).

A successful proof would show that the combined expression is nonnegative, rather than incorrectly assigning positivity to the full-theta measure alone.

## Adversarial check
The zero mode cannot be ignored: using the full theta function directly gives a divergent measure on \([1,\infty)\). This audit supersedes the earlier uncorrected modular-symmetry formulation.
