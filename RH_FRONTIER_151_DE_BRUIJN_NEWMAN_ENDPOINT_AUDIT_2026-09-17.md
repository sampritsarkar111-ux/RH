# Frontier 151E — de Bruijn–Newman Endpoint Audit — 2026-09-17

## Objective
Separate the exact de Bruijn–Newman reduction from the genuinely missing endpoint rigidity needed for RH.

## Proof-bearing question
Let the standard heat-flow family of the Riemann Xi kernel be represented by `H_t`. The route must prove an endpoint statement strong enough to force the critical parameter to the value required for RH. Merely proving a one-sided bound, or restating an RH-equivalent condition, does not close the problem.

## Required lemmas
1. Exact definition and normalization of the heat-flow parameter.
2. Preservation/continuation properties needed for the relevant entire-function class.
3. A rigorous theorem connecting real-zero preservation to the parameter range.
4. An independent endpoint rigidity mechanism forcing the required endpoint value.
5. Exact passage from that endpoint statement to real zeros of Xi and hence RH.

## Adversarial test
Any argument that begins by writing the zeros as `1/2 + i t` is circular. Any argument that assumes the endpoint value it is supposed to prove is circular. Numerical estimates are diagnostic only.

## Current status
This is a proof target, not a proof. The project should seek a theta/modular identity for the endpoint obstruction and record an exact residual if the desired rigidity fails.
