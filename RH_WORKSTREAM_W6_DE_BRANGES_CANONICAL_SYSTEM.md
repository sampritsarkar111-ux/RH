# W6 — de Branges / Canonical-System Route

Construct the completed Xi function's candidate Hermite–Biehler/canonical-system structure directly from the theta kernel.

Targets:
1. Define the candidate de Branges function and kernel exactly.
2. Prove positivity of the kernel without assuming RH.
3. Establish self-adjointness of the associated operator/canonical system.
4. Prove the exact zero-to-spectrum correspondence.
5. Show that the spectral reality theorem forces every nontrivial zeta zero to have real spectral coordinate, hence critical-line location.

Any step whose proof already uses real zeros is circular and must be rejected.
