# Frontier 69 — modular-pairing target

## Purpose

Frontier 68 eliminates the simplest pointwise-sign certificate for the exact fourfold cubic kernel. The next route is to exploit the theta kernel's modular symmetry before taking the sign.

Let the even theta-derived kernel satisfy the standard inversion relation in a logarithmic variable \(x\), with the zero-mode correction already isolated. The corrected even object obeys
\[
\rho_0(-x)=\rho_0(x).
\]
The key point is that evenness alone is insufficient for Jensen hyperbolicity; the desired argument must extract a genuinely sign-definite bilinear or quadratic form from the modular pairing.

## Target identity

For the cubic numerator \(B_n\), seek an exact decomposition
\[
\boxed{
B_n=\mathcal P_n^-+\mathcal R_n,
}
\]
where
\[
\mathcal P_n^-=-\int\!\int \mathcal A_n(x,y)^2\,d\mu_n(x)d\mu_n(y)\le0
\]
and \(\mathcal R_n\) is either zero or has a separately proved nonpositive sign from the modular involution. Every equality must be derived directly from the theta representation.

A second target is an exact paired kernel identity
\[
K_n(u_1,u_2,u_3,u_4)+K_n(Tu_1,Tu_2,Tu_3,Tu_4)
= -\mathcal V_n(u_1,u_2,u_3,u_4)^2+\mathcal E_n,
\]
where \(T\) is the exact modular variable transformation and \(\mathcal E_n\) has an independently established sign.

## Non-circularity gate

Reject any decomposition if it uses:

- RH or the reality of unknown zeros;
- Laguerre–Pólya membership as an input;
- a total-positivity theorem whose conclusion already implies RH;
- numerical fitting of coefficients followed by an asserted exact identity.

## Global significance

Even a successful proof of the cubic gate would cover only degree three. The ultimate target remains an all-degree theorem, for example a direct proof that the canonical Jensen polynomials
\[
J_{d,n}(X)=\sum_{j=0}^d\binom dj\gamma(n+j)X^j
\]
are hyperbolic for every \(d,n\), or an independent proof that \(\Xi\) lies in the Laguerre–Pólya class.
