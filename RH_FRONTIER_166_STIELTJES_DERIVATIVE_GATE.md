# RH Frontier 166 — Stieltjes Derivative Gate — 2026-09-17

A necessary consequence of a genuine Stieltjes representation

    F(x) = a + b/x + integral_0^infinity dmu(t)/(x+t),   x>0,

with a,b >= 0 and mu a positive measure, is

    (-1)^n F^(n)(x) >= 0

for every n >= 0 and x>0, whenever differentiation under the integral is justified. The pointwise derivative identity is

    d^n/dx^n (1/(x+t)) = (-1)^n n!/(x+t)^(n+1).

Thus an attempted theta-to-Stieltjes proof has a sharp falsifiable gate: prove these alternating derivative inequalities globally together with the Stieltjes growth/analyticity representation. Finite checks at a single point do not establish the theorem.

This gate is logically distinct from raw theta moment positivity because the required object is a nonlinear/logarithmic-derivative transform. The project's current ledger explicitly records this nonlinear bridge as open.
