# Frontier 37 verification

The central-coordinate substitution is an exact polynomial identity. Starting from
\[
\widetilde Q_d=dP_0-6H_0,
\]
with
\[
P_0=2vz-3w^2-6v^3,\qquad H_0=vz-w^2-v^3,
\]
substitution gives
\[
\widetilde Q_d=2(d-3)vz-3(d-2)w^2-6(d-1)v^3.
\]

At \(d=3\),
\[
\widetilde Q_3=-3w^2-12v^3,
\]
so \(\widetilde Q_3\ge0\) is equivalent to \(4(-v)^3\ge w^2\), necessarily with \(v\le0\).

Independent high-precision reconnaissance using the defining xi-function found the first several tested shifts consistent with this sign cone. This is only a computational check; it does not establish the universal inequality.

Important: Frontier 37 is a research reduction, not a proof of RH.
