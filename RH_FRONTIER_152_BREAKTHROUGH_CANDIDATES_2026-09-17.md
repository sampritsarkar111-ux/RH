# RH Frontier 152 — Breakthrough Candidate Equations and Theorem Gates

## Purpose
This frontier introduces new proof candidates in parallel. They are research conjectures/targets until every identity and analytic hypothesis is proved.

## 1. Pick/Weyl — modular-orbit positivity operator
For the exact theta-derived Pick numerator P(z), define a paired-orbit decomposition
`P(z)=Σ_O W_O(z)`, where each orbit O contains the full involution/modular partner set before lattice collapse. Candidate closure identity:

`W_O(z)=|A_O(z)|^2 + B_O(z)`, with `B_O(z)>=0`.

The breakthrough criterion is not merely finding A_O: it is proving B_O>=0 for every orbit and proving locally uniform summability. If B_O changes sign, the signed residual is the exact obstruction.

## 2. tau-Hankel — cumulant-to-Gram transform
Let tau_n denote the coefficients used by the project and let m_n be the underlying theta moments. Introduce the exponential generating relation
`M(t)=Σ m_n t^n/n!`, `K(t)=log M(t)=Σ k_n t^n/n!`.

The target is a theta-specific triangular transform `tau_n=T_n(k_1,...,k_n)` for which the Hankel form admits
`Σ_{i,j<=N} c_i c_j tau_{i+j}=||Σ_i c_i v_i||^2 + R_N(c)`,
`R_N(c)>=0`.

This would be a genuine new theorem only if the vectors v_i and residual are constructed explicitly from the unsummed theta lattice, with no zero input.

## 3. de Branges — inverse construction from Xi
Instead of guessing a Hamiltonian H(x), define finite-dimensional theta transfer matrices `T_N(x,z)` from exact theta blocks and seek a convergent canonical-system limit
`T(x,z)=lim_N T_N(x,z)`.

Candidate theorem gate: if `J=[[0,-1],[1,0]]`, `-J T_x=T A T` with `A(x)>=0` and the limiting de Branges structure function E satisfies
`Xi(z)=C E(z)` after an explicitly proved normalization, then self-adjointness forces real spectral zeros. Every step must be independent of RH.

## 4. Li/Weil — universal quadratic-form factorization
For the Weil quadratic form Q(g), seek an identity of the form
`Q(g)=Σ_r ∫ |L_r g(u)|^2 w_r(u)du + Q_arith(g)`,
where all weights are nonnegative and Q_arith is independently nonnegative from the prime/theta side. The key novelty target is a direct theta-to-SOS map rather than using zero locations.

## 5. de Bruijn–Newman — endpoint rigidity
For the heat-flow family H_t, formulate the rigidity target
`H_{t0} in Laguerre-Pólya AND H_t generated by the exact theta heat semigroup => t0 <= 0`.

The missing ingredient is an endpoint monotonicity/rigidity inequality strong enough to force the sign needed for RH. Merely restating the known equivalence with the Newman constant is not sufficient.

## 6. Cross-route bridge theorem candidate
If any one route proves a genuine positive spectral/Gram representation of Xi independent of its zeros, attempt to transfer it:

`positive Gram/Pick object -> all Hankel minors >=0 -> all Jensen discriminants >=0 -> Laguerre-Pólya closure -> Xi has only real zeros`.

This bridge itself requires proof; Hankel positivity alone is not being assumed sufficient.

## Falsification-first protocol
For each candidate: (i) derive exact low orders symbolically; (ii) calculate the first nontrivial residual; (iii) attempt a sign proof; (iv) test convergence assumptions; (v) if the candidate fails, record the smallest counterexample and replace it. Never upgrade a conjectural identity to a theorem.

## Completion criterion
Only an unconditional theorem that every nontrivial Xi zero is real closes the RH program. Until that happens, status remains OPEN.
